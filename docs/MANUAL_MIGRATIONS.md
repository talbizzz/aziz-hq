# Manual migrations

Declarative schemas in `supabase/schemas/` are the source of truth, but the diff tool does not track DML, publication membership, or grants on some objects. Every hand-written migration in `supabase/migrations/` must be listed here, or the drift check fails.

| Migration                                       | Reason                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `20261105110800_realtime_publication.sql`       | Publication membership (`supabase_realtime`: runs, tasks, gates, events, worker_heartbeats) and the `factory` module row are not tracked by the diff tool (ADR-4).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `20261105110810_lock_down_table_privileges.sql` | Default privileges give `anon`/`authenticated` TRUNCATE, REFERENCES, TRIGGER and MAINTAIN on new public tables, and the diff tool does not emit REVOKEs. Revokes them on existing tables and removes the default ACL for future ones, and removes PUBLIC's default EXECUTE on future functions. Mirrored in `supabase/schemas/15_grants.sql`.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `20261105142900_settings_defaults.sql`          | Default settings rows (timezone, quiet hours, digest time, worker-offline threshold) are DML, not tracked by the diff tool. Idempotent (`on conflict do nothing`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `20261105143000_telegram_cron_jobs.sql`         | The two `pg_cron` jobs (`flush_notifications` every minute, `worker_watchdog` every 3 minutes) are data in `cron.job`; not tracked by the diff tool. Idempotent (`cron.schedule` upserts by name).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `20261105150000_usage_policy_defaults.sql`      | The default `usage_policy` setting (sleeping hours, 5-hour caps, weekly margin and ceiling) is DML, not tracked by the diff tool. Idempotent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `20261105140800_active_overrides_grants.sql`    | Re-grants the view `active_overrides` after `20261105140755_usage_policy.sql` recreated it (the diff tool does not re-emit grants on a recreated view). Mirrored in `supabase/schemas/15_grants.sql`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `20261106100000_lockdown_api_privileges.sql`    | **Security fix found by verifying the first hosted push.** Supabase's hosted platform grants every new public function, table and sequence to `anon` and `authenticated` by default (the local stack does not), and the diff tool never emits REVOKEs; anon could execute all 45 public functions (incl. `telegram_config`) and held full table privileges. Revokes everything from `anon`/`authenticated`/PUBLIC, grants back exactly what the dashboard calls, makes `vault_secret` and `http_post_json` uncallable by any API role, and locks the default privileges. Idempotent. Default ACLs mirrored in `supabase/schemas/15_grants.sql`; privileges asserted by `supabase/tests/api_privileges_test.sql`, which simulates the hosted defaults first. |
| `20261106170000_transcripts_bucket.sql`         | T4.8: the private `transcripts` bucket (10 MiB, `text/plain`) and the `transcripts_owner_read` policy on `storage.objects` (owner at aal2 reads; nobody but `service_role` writes). Storage objects are not tracked by the diff tool. Idempotent. Asserted by `supabase/tests/transcripts_storage_test.sql`.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
